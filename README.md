### 🛡️ Антиплагиат и Условия вариативности (Анти-ИИ)

Чтобы работа была принята автоматическим скриптом, вы обязаны рассчитать индивидуальные размеры элементов для вашего **многострочного флекс-ряда карточек** на основе вашего имени и фамилии:

* **N = количество букв в вашей ФАМИЛИИ**
* **M = количество букв в вашем ИМЕНИ**

1. **Базовый размер карточки во флекс-ряду (`flex-basis`):** Должен быть равен строго: **`(N * 12) + 180px`**.
2. **Расстояние между элементами в контейнере (`gap`):** Задается для флекс-контейнера шапки и ряда карточек строго по формуле: **`(M * 2) + 4px`**.

---

### 🟢 Уровень: BASE (Максимум — 75 баллов)

**Технические требования:**
1. **Компонент Навигации (`<header>`):** Содержит логотип, список ссылок (`<nav> > <ul>`) и профиль пользователя. Элементы должны быть выстроены в линию вдоль главной оси (`row`). Распределение пространства — `justify-content: space-between`.
2. **Сетка контента (`<main>`):** Многострочный флекс-контейнер (`flex-wrap: wrap`), содержащий карточки статистики. 
3. **Формула вариативности:** Базовый размер карточки (`flex-basis`) должен быть равен строго: **`(N * 12) + 180px`**.
4. **Блок документации (Осознанность):** В самом конце файла `style.css` добавьте CSS-комментарий `/* Своими словами */` и развернуто ответьте на вопросы:
   * За счет какого свойства флекс-элементы удерживают свою высоту одинаковой в рамках одного ряда, даже если у них разное количество контента?
   * Какую роль выполняет значение `auto` в свойстве `flex-basis`?

---

### 🔵 Уровень: JUNIOR (Максимум — 90 баллов)

**Включает требования уровня BASE, а также:**
1. **Аномалия «Запрет на Pixel-Padding»:** Запрещено использовать жесткие пиксельные отступы (`margin`, `padding` в `px`) для расталкивания элементов внутри шапки и карточек. Все отступы между соседними флекс-элементами должны задаваться через нативное свойство контейнера `gap` (значение: **`(M * 2) + 4px`**).
2. **Магия автоматических отступов:** Кнопка «Выйти/Log out» в навигации должна быть физически оттолкнута в крайний правый угол за счет свойства `margin-left: auto`, а не за счет создания промежуточных пустых `div`-оберток.
3. **Жесткий Git-контроль:** В вашей ветке `homework-10` должно быть сделано **ровно 4 содержательных коммита** из VS Code. Каждый коммит должен начинаться со строгого семантического тега (коммиты без тегов или лишние коммиты завалят валидатор):
   * `[flex-nav]` Реализована шапка и верхнее меню навигации
   * `[flex-grid]` Сформирована многострочная сетка карточек контента
   * `[flex-card-inner]` Реализована вложенная вертикальная структура внутри карточек
   * `[flex-a11y]` Интегрированы стили фокуса фокус-визибл и клавиатурный тест
4. **В CSS-комментарий «Своими словами» добавляется вопрос:** Как поведет себя флекс-элемент, если ему задать комбинацию `flex: 1 0 auto` при дефиците места в контейнере?

---

### 🔴 Уровень: PRO (Максимум — 100 баллов)

**Включает требования уровней BASE и JUNIOR, а также:**
1. **Глубокая вложенная структура:** Внутри карточек `<article>` метаданные (стек, показатели, даты) должны быть размещены с использованием валидного списка определений (`<dl>`, `<dt>`, `<dd>`). Сам список `<dl>` должен стать флекс-контейнером, где пары `dt` и `dd` выравниваются по горизонтали, плавно переносясь на мобильных устройствах.
2. **Инженерный Стресс-тест на 320px:** Внутрь текстового блока одной из карточек необходимо поместить неделимое техническое слово длиной **не менее 36 символов** (например, `FlexboxContainerShrinkPropertiesOverflowTest`). Карточка должна быть настроена так, чтобы на разрешении 320px (эмуляция iPhone SE в DevTools) макет не разорвало по ширине, не появилось горизонтальной прокрутки, а слово корректно перенеслось по слогам (`overflow-wrap: break-word` / `hyphens: auto`).
3. **Реверсивный макет через CSS:** С помощью свойства `order` настройте интерфейс так, чтобы на десктопных экранах карточка с модификатором `.is-lead` (которая в HTML-коде идет самой первой) визуально отображалась в самом конце ряда, а на мобильных экранах возвращалась на первое место.
4. **Скриншот-доказательство:** Приложите к вашему Pull Request скриншот из DevTools в режиме эмуляции экрана 320px с включенной инспекцией флекс-контейнера шапки.
