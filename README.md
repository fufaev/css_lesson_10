# Практическая работа №10: Построение комплексных компонентных интерфейсов на CSS Flexbox

## 📋 Семантический сценарий и техническое задание

Вам необходимо разработать адаптивный макет панели управления (Dashboard) личного кабинета веб-приложения на основе предоставленного HTML-шаблона (`index.html`) и базовых стилей (`css/style.css`). Весь лейаут, распределение свободного пространства, адаптивность и внутренняя структура компонентов должны быть реализованы исключительно средствами **CSS Flexible Box Layout**.

## 🛡️ Антиплагиат и условия вариативности (Анти-ИИ)

Чтобы работа была принята автоматическим скриптом проверки, вы обязаны индивидуализировать параметры макета на основе количества букв в вашем имени и фамилии:

* **N = количество букв в вашей ФАМИЛИИ**
* **M = количество букв в вашем ИМЕНИ**

1. **Базовый размер карточки во флекс-ряду (`flex-basis`):** Должен быть равен строго: **`(N * 12) + 180px`**.
2. **Расстояние между элементами в контейнере (`gap`):** Задается для флекс-контейнера шапки и многострочного флекс-ряда карточек строго по формуле: **`(M * 2) + 4px`**.

Студенты, сдавшие макеты с идентичными или не соответствующими формуле параметрами, к защите не допускаются.

## 🟢 Уровень: BASE (Максимум — 75 баллов)

### Технические требования
1. **Компонент навигации (`<header>`):** Содержит логотип, список ссылок (`<nav> > <ul>`) и блок профиля. Элементы должны быть выстроены в линию вдоль главной оси (`flex-direction: row`). Распределение свободного пространства — `justify-content: space-between`.
2. **Макет контента (`<main>`):** Многострочный флекс-контейнер с разрешенным переносом элементов (`flex-wrap: wrap`), содержащий карточки статистики.
3. **Расчет параметров:** Базовая ширина карточек настраивается через свойство `flex-basis` строго по индивидуальной формуле **`(N * 12) + 180px`**.

## 🔵 Уровень: JUNIOR (Максимум — 90 баллов)

### Технические требования
1. **Включает все требования уровня BASE.**
2. **Аномалия «Запрет на Pixel-Padding»:** Запрещено использовать жесткие пиксельные отступы (`margin`, `padding` в `px`) для формирования расстояний между компонентами шапки и карточек. Все отступы между соседними флекс-элементами должны задаваться через нативное свойство контейнера `gap` со значением **`(M * 2) + 4px`**.
3. **Магия автоматических отступов:** Кнопка «Выйти из системы» в навигации должна быть физически оттолкнута к правому краю за счет свойства `margin-left: auto` у самого элемента (использование пустых `div`-оберток для распределения элементов запрещено).

### Требования к истории коммитов
В вашей рабочей ветке `homework-10` должно быть сделано **ровно 4 или 5 содержательных коммитов** из VS Code. Каждый коммит обязан начинаться со строгого семантического тега:
* `[flex-nav]` Реализована шапка и верхнее меню навигации.
* `[flex-grid]` Сформирован многострочный флекс-ряд карточек контента.
* `[flex-card-inner]` Реализована вложенная вертикальная структура внутри карточек.
* `[flex-a11y]` Интегрированы стили фокуса `:focus-visible` и проведен клавиатурный тест.

## 🔴 Уровень: PRO (Максимум — 100 баллов)

### Технические требования
1. **Включает все требования уровней BASE и JUNIOR.**
2. **Глубокая вложенная структура:** Внутри карточек `<article>` метаданные проекта должны быть размещены с использованием семантического списка определений (`<dl>`, `<dt>`, `<dd>`). Сам список `<dl>` должен быть переведен в режим `display: flex`, где пары `dt` и `dd` выравниваются по горизонтали и адаптивно переносятся на узких экранах.
3. **Инженерный стресс-тест на 320px:** Внутрь текстового блока одной из карточек помещено неделимое техническое слово длиной 46 символов (`Критическая_ошибка_модуля_FlexboxContainerShrinkPropertiesOverflowTest...`). Вам необходимо настроить свойства `overflow-wrap: break-word` или `word-break` так, чтобы на разрешении 320px макет не разрывало по ширине и не появлялась горизонтальная прокрутка.
4. **Реверсивный макет через CSS:** С помощью свойства `order` настройте интерфейс так, чтобы на десктопных экранах (от 1024px) карточка с модификатором `.is-lead` (которая в HTML-коде идет первой) визуально отображалась в самом конце ряда, а на мобильных экранах возвращалась на первое место.
