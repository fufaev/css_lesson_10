## Цель работы

Изучение CSS Flexbox и его применения для построения адаптивных компонентных интерфейсов.

## Индивидуальные параметры

- N — количество букв в фамилии: 4.
- M — количество букв в имени: 4.
- flex-basis: (4 * 12) + 180 = 228px.
- gap: (4 * 2) + 4 = 12px.

## Реализация

### BASE

- Горизонтальная навигация на Flexbox.
- Многострочный флекс-контейнер карточек.
- Индивидуальное значение flex-basis.
- Одинаковая высота карточек в пределах ряда.

### JUNIOR

- Расстояния между компонентами через gap.
- Позиционирование кнопки выхода через margin-left: auto.
- Вложенная структура карточек на Flexbox.
- Стили клавиатурного фокуса focus-visible.
- Семантические сообщения коммитов.

### PRO

- Вложенные флекс-контейнеры списков определений.
- Перенос длинного технического текста через overflow-wrap.
- Адаптивность интерфейса на ширине 320px.
- Изменение порядка карточек через order при ширине от 1024px.
